# 🚦 VisionForce — Интеллектуальная система видеоаналитики дорожного движения

Платформа видеоаналитики дорожного движения и оптики светофоров в реальном времени. Система выявляет нарушения ПДД, анализирует скорость ТС, определяет фактический цвет светофоров через оптический фотометрический алгоритм и прогнозирует потенциально опасные ситуации (TTC).

---

## 📌 Ключевые возможности системы

### 1. Оптический CV-анализ светофоров (Optical Traffic Light CV)
- **Прямой спектральный анализ кадра:** алгоритм считывает цветовую насыщенность (HSV/RGB) в области ROI светофора на видео без привязки к искусственным фазам.
- **Определение активного сигнала:** точное определение `КРАСНОГО`, `ЖЕЛТОГО` и `ЗЕЛЕНОГО` сигналов светофора с цветовыми гистограммами и порогами освещенности.
- **Интерактивное обведение ROI:** оператор может выделить любой светофор в кадре мышью для моментального подключения оптического фотометрического детектора.

### 2. Детекция и трекинг объектов (Object Detection & Tracking)
- **Нейросетевая детекция:** выявление транспортных средств (`car`, `bus`, `truck`, `motorcycle`, `bicycle`) и пешеходов (`person`).
- **Сглаживание и кинематика:** алгоритм расчёта мгновенной скорости в км/ч по траектории движения объектов на холсте.

### 3. Фиксация нарушений и контроль правил ПДД (КоАО РУз)
- **Проезд на красный свет (ст. 128-4 КоАО РУз):** фиксация пересечения стоп-линии при запрещающем сигнале светофора.
- **Выезд за стоп-линию (ст. 128 КоАО РУз):** контроль фиксации остановки перед стоп-линией.
- **Пешеход в неположенном месте (ст. 138 КоАО РУз):** мониторинг нахождения пешехода на проезжей части вне «зебры».
- **Превышение скорости:** фиксация ТС с превышением установленного лимита.
- **Предиктивный риск (TTC < 2.0s):** вычисление времени до потенциального столкновения (Time-To-Collision) между объектами.

### 4. Веб-интерфейс и плеер анализа
- **60 FPS Canvas Отрисовка:** плавный рендеринг видеопотока, траекторий, плашек скорости и светофоров.
- **Покадровая навигация:** точный переход на ±1 кадр (0.04с) и ±5 секунд, поддержка горячих клавиш (`Space`, `<`, `>`).
- **Реестр нарушений и Click-to-Jump:** мгновенный переход к таймкоду фиксации нарушения.
- **Электронное постановление:** генерация формы протокола об административном правонарушении МВД РУз с функцией печати.

## 🛠 Технологический стек

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS
- **Computer Vision & AI Engine:** TensorFlow.js COCO-SSD, Optical Photometry Engine, HTML5 Canvas API
- **Иконки и стиль:** Lucide React, Tailwind Typography
- **Формат данных:** JSON predictions & protocol exports

## 💻 Установка и запуск

### Требования
- Node.js >= 18.0.0
- npm >= 9.0.0

### Локальный запуск
```bash
# 1. Клонирование репозитория
git clone https://github.com/XMIRKA/Litecamera.app.git
cd Litecamera.app

# 2. Установка зависимостей
npm install

# 3. Запуск dev-сервера
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

### Сборка для продакшена
```bash
npm run build
```
